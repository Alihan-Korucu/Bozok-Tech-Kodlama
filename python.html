Python Temelleri

Python dünyanın en popüler programlama dillerinden biridir. Yapay zeka, veri bilimi, web geliştirme ve otomasyon alanlarında kullanılır.

💡 Python'un en büyük avantajı okunabilir ve öğrenmesi kolay olmasıdır.

1. Ekrana Yazı Yazdırma

print("Merhaba Dünya")

print() komutu ekrana çıktı verir.

2. Değişkenler

isim = "Ali" yas = 15 print(isim) print(yas)

Verileri saklamak için değişkenler kullanılır.

3. Veri Tipleri

isim = "Ali" # String yas = 15 # Integer boy = 1.75 # Float aktif = True # Boolean

4. Kullanıcıdan Veri Alma

isim = input("Adınız: ") print("Merhaba", isim)

5. Matematik İşlemleri

a = 10 b = 5 print(a + b) print(a - b) print(a * b) print(a / b)

6. If Else Kullanımı

yas = 18 if yas >= 18: print("Ehliyet alabilirsiniz") else: print("Yaşınız yetmiyor")

7. For Döngüsü

for i in range(5): print(i)

0'dan 4'e kadar sayıları yazdırır.

8. While Döngüsü

sayi = 0 while sayi < 5: print(sayi) sayi += 1

9. Listeler

meyveler = ["Elma", "Muz", "Çilek"] print(meyveler[0])

Birden fazla veriyi tek değişkende tutar.

10. Liste Döngüsü

meyveler = ["Elma","Muz","Çilek"] for meyve in meyveler: print(meyve)

11. Fonksiyonlar

def selamla(): print("Merhaba") selamla()

12. Parametreli Fonksiyon

def selamla(isim): print("Merhaba", isim) selamla("Ali")

13. Return Kullanımı

def topla(a,b): return a+b sonuc = topla(5,3) print(sonuc)

14. Sözlükler (Dictionary)

ogrenci = { "isim":"Ali", "yas":15 } print(ogrenci["isim"])

15. Try Except

try: sayi = int(input("Sayı: ")) except: print("Geçersiz giriş")

16. Dosya Yazma

dosya = open("not.txt","w") dosya.write("Merhaba") dosya.close()

17. Dosya Okuma

dosya = open("not.txt","r") print(dosya.read()) dosya.close()

18. Modül Kullanımı

import random print(random.randint(1,10))

19. Sınıflar (OOP)

class Araba: def __init__(self, marka): self.marka = marka araba = Araba("BMW") print(araba.marka)

20. Yapay Zeka İçin Python

import numpy as np sayilar = np.array([1,2,3]) print(sayilar)

NumPy, Pandas, TensorFlow ve PyTorch gibi kütüphaneler Python'u yapay zeka alanında çok güçlü hale getirir.

Mini Proje 1 - Sayı Tahmin Oyunu

import random hedef = random.randint(1,10) tahmin = int(input("Tahmin: ")) if tahmin == hedef: print("Kazandın!") else: print("Kaybettin!")

Mini Proje 2 - Hesap Makinesi

a = int(input("1. sayı: ")) b = int(input("2. sayı: ")) print("Toplam =", a+b)
